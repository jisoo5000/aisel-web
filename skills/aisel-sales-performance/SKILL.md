운영시트 ‘신상성과’를 디자이너 화면의 읽기 원본으로 쓰는 방식은 사용자 선호로 기록한다. 카페24는 실제 판매·반품 근거이며 시트 확인 결과를 앱으로 연결하는 구조를 검토한다. 시트 연결·공유 범위·인증 변경은 아직 구현하지 않았다. 현재 로그인은 비공개 Firebase 읽기 권한 때문에 필요하며 임의로 우회하지 않는다. 과거 v103–v105의 항상 보이는 스크롤바/목록 품번·기록 버튼 기준은 이 최신 결정으로 대체한다.

## v107 · 2026-10-07 운영시트 판매성과 연결

사용자의 ‘응 해줘’로 순위·상품명·디자이너·공장·전체 판매 비중·반품률 6개 항목의 로그인 없는 공유를 승인했다. 원본 운영DB는 소유자만 접근하는 비공개 상태를 재조회했다. 독립 Apps Script는 Sheets API 읽기 전용 권한으로 고정 sheetId 2026100512의 상품표만 읽는다.
