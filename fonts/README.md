# AISEL Screen font assets

Derived from Pretendard v1.3.9 by Kil Hyung-jin, under the SIL Open Font License in LICENSE.txt. Source: https://github.com/orioncactus/pretendard/tree/v1.3.9

Family renamed to AISEL Screen; glyph subsets and variable weight range 400–700 only. Latin/symbols, KS X1001 Hangul, and remaining source codepoints are split into three unicode-range files. No source character coverage is dropped. Screen CSS alone declares this family; the original Pretendard print fallback is not registered or modified. No external font service is called at runtime. Versioned file paths allow browser caching.
