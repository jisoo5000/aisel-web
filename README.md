# AISEL 직원 공유 화면

- [제품 진행 현황](https://jisoo5000.github.io/aisel-web/status.html)
- [작업지시서](https://jisoo5000.github.io/aisel-web/work-order-5aa994e7.html)
- 발주서 및 위 화면에 필요한 실행 자산

이 저장소는 직원용 화면을 배포하는 공개 저장소입니다. 화면·실행 자산과 기존 판매현황 실행/검증 코드를 유지합니다. 코어·원가 기준·가격 정책·상품 매핑·내부 운영 문서는 비공개 원본 저장소에서 관리합니다.

공개 저장소의 파일은 인터넷에서 읽을 수 있습니다. 실제 업무 데이터의 접근 권한은 앱 인증과 서버에서 적용하며, 숨긴 주소나 폴더명은 권한을 대신하지 않습니다.

유지보수: 비공개 원본의 배포 허용 목록을 사용하세요. `docs/`, `skills/`, 내부 기록·단독 원가계산기를 이 저장소에 다시 추가하지 마세요. 직원이 사용하는 기존 화면 주소와 의존 자산을 보존하세요.
