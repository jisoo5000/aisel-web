앱 연계는 선택 사항이다. 필요하면 같은 검증 결과 중 순위·상태·게이지·기준일만 기존 보호 경로로 제공하는 안을 권한다. 운영 파일을 브라우저에서 직접 읽는 방식은 파일 접근 권한과 열 구조 변경에 앱이 의존하게 하므로 우선 권하지 않는다. 시트 연결 자동 실행에 AI를 넣을 필요는 없다. 대상 운영 시트와 실제 표시 열은 구현 시 기존 설정을 확인한다. 이번에는 검토 기록만 갱신했으며 시트 작성·코드 수정·배포·예약 변경은 하지 않았다. 작은 검토 메모 추가이므로 별도 버전 ZIP은 만들지 않았고 v6 복구본을 보존한다.
