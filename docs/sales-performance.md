# 에이슬 작업지시서 판매성과 v95

기준일: 2026-10-03 · 시간대: Asia/Seoul

## 목적과 확정 구성

판매성과를 제품 개발에 참고할 수 있는 성적표로 제공한다. 카페24 실제 판매를 사용하며 메타 광고 점수는 순위에서 제외한다. 수기로 목표수량·판매수량·달성률을 입력하는 방식 대신 실제 집계 결과를 표시한다.

목록은 순위, 기존 작은 제품 사진, 품명·품번, 판매 게이지와 한글 평가로 구성한다. 기존 이미지를 재사용하며 원본사진 복사본을 새로 저장하지 않는다. 성과 우수는 네이비, 보통은 블루그레이, 성과 부진은 채도가 높은 와인색 `#A3264C`, 판단 대기는 회색으로 표시한다.

제품을 펼치면 순판매수량, 확인 가능한 순매출, 취소·반품 수량과 판단 사유가 나온다. 기존 개선 기록은 해당 제품의 메모 필드만 읽고, 수정은 작업지시서를 여는 경로로 연결한다. 판매중·판매준비·전체 필터와 품명·품번 검색을 유지한다.

## 집계 기준

- 한국 시간 전날까지 연속 14일 동안 결제된 주문을 집계한다.
- 해당 주문에 연결된 취소·반품 수량을 제외한다. 다른 기간 주문의 반품을 현재 판매에서 무조건 빼지 않는다.
- 같은 제품의 색상·사이즈 옵션을 합산한다. 정확한 상품 연결이 안 되면 연결 확인 상태로 남긴다.
- 순판매수량으로 정렬하고 확인 가능한 순매출을 동률 비교에 활용한다. 매출 근거가 부족해도 확인된 판매수량을 숨기지 않는다.
- 순위와 성과 판정은 구분한다. 신상품·출시일 미확인·재고 이력 부족은 부진으로 단정하지 않는다.
- 예약 실행은 매일 오전 6시 한국 시간으로 준비한다. 일반 서버 코드가 수집·계산하므로 반복 실행에 AI 호출을 사용하지 않는다. API·호스팅·Firebase 사용량은 별도다.

## 보관 데이터와 보안

요약 데이터에는 집계 기간·생성 시각·상품별 판매 숫자·순위·평가 상태만 허용한다. 주문 원문, 고객정보, 원본사진, 인증 토큰은 공개 프로젝트와 판매 요약에 포함하지 않는다. 기존 사진을 재사용하므로 이 기능 때문에 사진 사본이 매일 쌓이지 않는다.

기존 GitHub Pages와 승인된 Site 호스팅을 유지한다. Site 호스팅의 현재 공개 상태는 그대로 두고 판매 집계 API를 접근 인증과 별도 서비스 인증으로 보호한다. Firebase 규칙이 실제 권한을 검증하며 로그인 버튼은 보안 규칙의 대체 수단이 아니다. 판매 로그인으로 기존 작지의 시트 반영·사진 갱신 콜백이 실행되지 않도록 별도 앱을 사용한다.

권한 거절·자료 누락·상품 미연결은 판매 0과 구분한다. 마지막 정상 결과가 있는 단순 갱신 실패는 그 결과와 갱신 시각을 유지한다. 로그아웃·권한 상실 때는 판매 데이터 캐시를 제거한다. 불완전 집계를 정상 결과 위에 게시하지 않는다.

## 검증과 남은 작업

프런트엔드 후보는 55개 검증을 통과했다. 320~1280px 화면, 정렬·검색·상세 펼침, 0과 미확인 구분, 한글 사유, 인증 분리, 로그아웃 중 응답 경합을 포함한다. 러너 135개 검증은 구현 준비의 근거이며 실제 예약 실행 성공의 증거는 아니다. 최종 러너 설정은 전체 처리 최대 35분, 상태 조회 최대 300회, GitHub 작업 최대 40분이며 서버의 대기 권고는 0~300초만 허용한다.

남은 작업은 배포된 판매 집계 API의 전용 접근 권한 등록, 권한 등록 후 워크플로 첫 실제 실행, 실제 집계 수집·요약 저장·재조회 검증, 소유자 화면에서 실제 판매 결과 확인이다. API 배포, GitHub 비밀값 6개 설치, 러너·워크플로 게시·푸시는 이미 완료했다. 예약 설정 배포와 실제 집계 성공을 구분하며 완료 시 [상태 JSON](sales-performance.json)을 함께 갱신한다.

요청된 전달 구성은 이 기획 MD, 비밀값 없는 JSON, 재사용 스킬 폴더와 승인된 코드다. 승인된 저장소는 [jisoo5000/aisel-web](https://github.com/jisoo5000/aisel-web)이다. 원본 패키지 커밋·푸시 및 v1 ZIP·Drive 업로드는 완료했다. 이후 달라진 운영 상태를 반영한 현재 MD·JSON은 로컬 수정본이며, 별도 게시 전까지 기존 커밋과 v1 백업의 내용이 자동으로 바뀌지는 않는다.
