작지 현재화면 백업

  1. 이 링크를 즐겨찾기 모음으로 끌어 놓기
  2. 사진·금액을 입력한 원래 작지 탭으로 돌아가기
  3. 방금 만든 ‘작지 현재화면 백업’ 즐겨찾기 누르기
  4. 다운로드된 JSON 파일을 대화에 첨부하기

현재 화면의 입력값·사진 주소·저장 진단 상태만 파일로 내보냅니다. 서버와 기기 초안을 수정하거나 새로고침하지 않습니다. 사진이 주소로만 남은 경우 원본 파일 확보는 별도 확인이 필요합니다.

이 브라우저에 보관된 초안을 파일로 내려받습니다. 작업지시서와 서버 내용은 변경하지 않습니다.

초안을 확인하고 있습니다…
